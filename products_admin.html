Выпуск услуг

Настройте перевод, стоимость и компоненты услуги для выбранной подкатегории.

Новая услуга

1. Категория и услуга

Название категории останется без изменений; для услуги будет сохранено отдельное название.

2. Перевод

Шаблон заменит языки, цену и компоненты, сохранив название и описание услуги. Это копия: изменения шаблона не обновят услугу. «Без шаблона» убирает только связь, сохраняя введённые данные.

3. Компоненты услуги

Цена услуги = базовая стоимость + цены обязательных компонентов. Необязательные компоненты оплачиваются по выбору клиента.
